Cheat sheet

One page. Prints well. Terms follow the glossary.

The API

CallDoes
POST /scansStarts a scan and waits for it to end. Returns the report.
GET /scans/<id>Returns the saved REPORT.md.
GET /scans/<id>/<file>Returns another saved file, for example findings.json.

Every call needs the header authorization: Bearer <SCAN_API_TOKEN>.

Request body fields

FieldValuesDefault
repo (required)https://github.com/owner/name (public)
skilllite, fulllite
modelclaude-haiku-5-5, claude-sonnet-5-5MODEL var (sonnet)
effortlow, medium, high, xhigh, maxEFFORT var (high)
max_budget_usdmore than 0, at most MAX_BUDGET_USDthe ceiling (2)
profile (full only)quick, standard, deepquick
budget (full only)integer 1 to 200 (agent runs)none

Status codes

200Scan finished. Body has scanId, the settings, files, report.
400A field is not valid. The message lists the allowed values.
401Missing or wrong bearer token.
502The scan failed. Body has scanId and error (with the agent log tail).

Example

curl -m 900 https://elise-engine-api.mochi-project.workers.dev/scans \
  -H "authorization: Bearer $SCAN_API_TOKEN" \
  --json '{"repo":"https://github.com/octocat/Hello-World",
           "skill":"lite","model":"claude-haiku-5-5",
           "effort":"low","max_budget_usd":1}'

Commands (run in apps/elise-engine-api)

pnpm --filter elise-engine-api build     # type-check
pnpm --filter elise-engine-api lint
pnpm exec wrangler deploy                 # builds the image, so Docker/Colima must run
pnpm exec wrangler tail                   # live logs
pnpm exec wrangler containers list
pnpm exec wrangler containers instances <ID>
pnpm exec wrangler r2 bucket info repo-scan-reports
pnpm exec wrangler secret put ANTHROPIC_API_KEY   # paste in your terminal, never in chat

Numbers to remember

Container typestandard-1: 1/2 vCPU, 4 GiB memory, 8 GB disk. (lite has 256 MiB.)
Poll interval5 seconds for agent.exit
Agent time limit40 minutes
Clone time limit5 minutes
Allowed hostsgithub.com, api.anthropic.com

Rules

  1. The container never holds the real key.
  2. A finding is a lead. A person checks it.
  3. No findings does not mean safe.
  4. Change one thing at a time when you debug.
  5. Read the Anthropic usage page after each test.

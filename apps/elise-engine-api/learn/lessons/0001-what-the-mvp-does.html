What the MVP does

About 5 minutes. Mission: understand and operate elise-engine-api.

Your win: after this lesson, you can name the five parts of the MVP and say what each part does.

The idea

You send the Worker a GitHub URL. The Worker starts a sandbox. The sandbox clones the repo. An agent reads the code and writes a security report. The Worker saves the report in an R2 bucket. Then the Worker destroys the sandbox.

Each scan has its own sandbox. No scan can see the files of another scan.

The five parts

PartJob
WorkerReceives the request, checks the token, starts the sandbox, saves the files, and returns the report.
Durable ObjectStarts the container and sends commands to it. Code: ScanSandbox.
ContainerA Linux machine. It runs git and the agent.
AgentClaude Code. It reads the repo and writes REPORT.md and findings.json.
R2 bucketKeeps the saved files after the container is gone.
Limits. The MVP scans public GitHub repos only. The report is a first pass. A report with no findings does not prove the code is safe (lesson 7).

Check your memory

Which part holds the files after a scan ends?

The Worker saves the files in R2. The container is destroyed, and its disk goes with it.

Which part reads the repo code and finds problems?

The agent does the review. The Durable Object only starts and controls the container.

What happens to the container when a scan ends?

The Durable Object destroys the container in a finally block, so it happens on success and on failure.

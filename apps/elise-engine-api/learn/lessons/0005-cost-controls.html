Cost controls

About 7 minutes. Before this: lesson 4.

Your win: after this lesson, you can set the cost limits for a scan, and say what each limit does and does not do.

Where the money goes

Each scan costs money in two places:

  • Anthropic: you pay for the tokens the agent reads and writes. This is the large cost.
  • Cloudflare: you pay for the container while it runs. The scan is short, so this is the small cost.

We have not measured the dollar cost of a scan. Read the usage page in the Anthropic Console after each test. A repo with one file costs far less than a real project, so do not use that number to plan.

The layers

We use several limits. Each limit is a layer. A scan must pass through all of them.

The levers

LeverWhere you set itWhat it does
max_budget_usdRequest bodyHard dollar cap for one scan. A value above the ceiling gets a 400 error.
MAX_BUDGET_USDwrangler.jsoncThe ceiling. Change it and deploy to raise it.
skillRequest bodylite (default) or full.
effortRequest bodylow to max. Higher effort uses more tokens.
modelRequest bodyclaude-haiku-5-5 or claude-sonnet-5-5.
profile, budgetRequest bodyFull skill only. Fewer waves and a cap on agent runs.

What the cap does not do

  • When the cap stops a scan early, the report may not exist. The Worker then returns an error and saves nothing. We do not keep partial files yet.
  • The cap only covers the Claude Code process. It does not cover the Cloudflare container time.
  • Claude Code can show its own cost estimate with --output-format json (total_cost_usd). The docs say it is a client-side estimate and can differ from your bill. We do not record it yet. That is a good first improvement.

Check your memory

Which setting is a hard stop on dollars for one scan?

The cap becomes --max-budget-usd. The other settings lower the usual cost but set no maximum.

A request asks for max_budget_usd 5, and the ceiling is 2. What happens?

The Worker checks that the value is more than 0 and at most the ceiling. A higher value is rejected.

Which limit do you set in the Anthropic Console?

It is the last backstop if a bug ignores every limit in our code.

Wait, what? Re-pitch this lesson

Context. The agent uses paid model calls. A stuck or large scan could cost a lot.

Short version. We stack limits. The Anthropic monthly limit is the outer layer. The Worker ceiling is next. Each request can set a lower cap. Choices such as effort and model lower the usual cost.

Remember. Hard stops: the monthly limit and the cap. Everything else only helps.

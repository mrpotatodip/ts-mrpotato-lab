# Glossary Map

## Contexts

- [Amelie](./apps/amelie-engine-api/GLOSSARY.md): AI customer assistant that answers a small business's customer questions from its own information (parties, tenants, threads, menu imports)
- [Elise control plane](./apps/elise-control-plane-api/GLOSSARY.md): where agents are created, versioned and test-run, separate from Amelie
- [Elise engine](./apps/elise-engine-api/GLOSSARY.md): scan service that clones a public GitHub repo into a sandbox, runs an AI security review, and keeps the report (scans, sandboxes, accounts)
